All Sim Offer Android APK project

এই প্রজেক্টটি আপনার ওয়েবসাইটকে Android WebView অ্যাপে দেখায়।
অ্যাপের নাম: All Sim Offer
Package ID: com.allsimoffer.app
ওয়েবসাইট: https://all-sim-offer-2.onrender.com/

APK এখনো তৈরি/সাইন করা হয়নি। এই সোর্স থেকে GitHub Actions দিয়ে Debug APK তৈরি হবে।

সহজ পদ্ধতি:
1. ZIP ফাইলটি Extract করুন।
2. আপনার GitHub repository https://github.com/zafor24/all-sim-offer এ যান।
3. Add file > Upload files দিয়ে এই ZIP-এর ভেতরের ফাইল ও ফোল্ডারগুলো রিপোজিটরির মূল জায়গায় আপলোড করুন।
   (ZIP ফাইলটি নিজে আপলোড করবেন না; ZIP খুলে ভেতরের সবকিছু আপলোড করবেন।)
4. Commit changes দিন।
5. GitHub-এর Actions ট্যাবে যান।
6. "Build All Sim Offer APK" workflow চলবে। সবুজ টিক এলে workflow খুলুন।
7. নিচে Artifacts থেকে "All-Sim-Offer-Android-APK" ডাউনলোড করুন।
8. ZIP খুললে app-debug.apk পাবেন। Android ফোনে ইনস্টল করতে হবে।

নোট:
- এটি Debug APK; Play Store-এ প্রকাশের জন্য আলাদা release signing দরকার।
- সাইটে পরিবর্তন করলে অ্যাপেও নতুন কনটেন্ট দেখা যাবে, কারণ অ্যাপটি লাইভ ওয়েবসাইট লোড করে।
- Render Free সার্ভার ঘুমিয়ে থাকলে অ্যাপ প্রথমবার খুলতে দেরি হতে পারে।
- পেমেন্ট বা অপারেটর API সংযোগ এই অ্যাপ নিজে থেকে যোগ করে না।
